# comini-walkthroughs

Maths concept walkthroughs for Comini assessments and atlas.

Each concept is an independent Next.js app in its own subfolder — no shared root dependencies. `cd` into a folder, `npm install`, then `npm run dev`.

| Folder | Concept |
| --- | --- |
| [`place-value-explainers`](place-value-explainers) | Place values |
| [`compare-order-explainers`](compare-order-explainers) | Compare & order numbers |
| [`skip-counting-explainers`](skip-counting-explainers) | Skip counting |
| [`rounding-explainers`](rounding-explainers) | Rounding numbers |
| [`subtraction-explainers`](subtraction-explainers) | Subtraction |
